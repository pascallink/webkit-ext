Markdown nach Jira

Wandelt Markdown aus Azure DevOps in Jira-Markup um und fuegt es direkt in das Ticket ein.

Verhalten

Beim Einfuegen (Strg+V) in ein Jira-Feld wird Markdown erkannt und umgewandelt. Wird Text eingefuegt, der kein Markdown ist, aber danach aussieht, hilft das Ausschalten. Derselbe Schalter sitzt im Popup, im Panel auf der Jira-Seite und im Kontextmenue des Erweiterungssymbols; ein Badge am Symbol zeigt den Zustand.

In reine Textfelder wird immer Jira-Markup geschrieben. Damit Jira es auch anzeigt, muss das Feld den Wiki Style Renderer verwenden (Administration → Vorgaenge → Feldkonfigurationen).

Wenn das Feld ein Rich-Text-Editor ist

Betrifft Jira Cloud sowie Jira Server / Data Center mit aktiviertem Rich-Text-Editor (jira.rte.enabled). Ein solcher Editor zeigt Jira-Markup woertlich an, statt es zu formatieren.

Konvertierung

Eigene Jira-Adressen (Server / Data Center)

Ohne Eintrag laeuft die Erweiterung nur auf *.atlassian.net (Jira Cloud). Fuer Jira Server oder Data Center hier die Adresse eintragen, eine pro Zeile – z. B. jira.firma.de. Port und Pfad koennen mit angegeben werden, sie werden abgeschnitten; http und https sind beide abgedeckt. Anschliessend auf Zugriff erlauben klicken und die Jira-Seite neu laden.
